## 📖 About
WanderLust is a **full-stack MERN travel listing application**.  
Users can explore travel destinations, view listings, and interact with a dynamic backend API.  

This project uses **Node.js, Express, MongoDB, EJS, and CSS** for a seamless full-stack experience.

## 🛠️ Tech Stack
- **Frontend:** EJS, HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** MongoDB (Atlas)
- **Cloud Services:** Cloudinary for image hosting, Mapbox for map integration
- **Hosting:** Render

## 📂 Features
- Browse and explore travel listings easily
- Connects with a backend API to fetch and update data dynamically
- Users can comment on and rate other users' listings
- Keeps user accounts and sessions secure
- Shows locations on maps using Mapbox
- Allows uploading and managing images with Cloudinary
